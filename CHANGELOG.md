## [1.0.0] — 2025-01-01

### Added
- 🛡 Log analyzer with threat pattern detection (SSH brute force, SQLi, XSS, privilege escalation)
- 🗺 Nmap output parser with port risk assessment
- 🔒 CVE and vulnerability explainer knowledge base
- 🔐 Password strength checker with entropy calculation
- 💻 Code reviewer with multi-language static security analysis (Python, JS, C, SQL)
- 📝 Code generator with templates (CLI, Flask API, Express API, C tool, scanner)
- 🧪 Unit test generator for Python and JavaScript
- 📁 Project scaffold creator (python-cli, python-api, security-tool, node-api)
- 🧠 Agent brain with LLM routing and tool dispatch
- 💾 Persistent memory (SQLite — messages, reports, notes)
- ⚙ System tools (safe file reading, whitelisted commands)
- 🖥 Interactive CLI with rich terminal formatting
- 📋 GitHub documentation (README, ROADMAP, CONTRIBUTING, SECURITY)
- ✅ CI/CD pipeline with GitHub Actions
- 🎯 One-shot mode (--analyze-log, --review-code flags)
